# Reference_eval_scenarios — career-mentor skill 三情境迴歸評測

依據:`dev/Reference_skill_modernization.md` 第 17 條(Evaluation-driven:重寫後建 3 個測試情境實測觸發與流程遵循,不憑感覺驗收)。
本文件是可重複執行的迴歸資產:skill 每次改版後照「執行方式」重跑,把新結果追加到「歷次結果」。

## 受測物

`DEPLOYMENT/Claude_Code/output/`(SKILL.md + references/)——progressive disclosure 版 career-mentor skill。

## 執行方式(每次重跑相同)

1. 建測試專案(scratchpad 或任一暫存目錄),把受測物複製為 `<testdir>/.claude/skills/career-mentor/`:
   ```bash
   mkdir -p <testdir>/.claude/skills
   cp -r "D:/000 Projects/Toolkit_Career_Mentor/DEPLOYMENT/Claude_Code/output" <testdir>/.claude/skills/career-mentor
   ```
2. 在 `<testdir>` 內用 Claude Code headless 跑情境(首則新對話用 `claude -p`,後續輪次用 `claude -p --continue` 續同一對話;`--continue` 續的是「該目錄最近一次對話」,故三情境共用一個測試目錄時,情境 1 與情境 2 之間必須以不帶 `--continue` 的新對話分隔):
   ```bash
   cd <testdir>
   claude -p "<訊息>" --max-turns 4 > transcript.txt
   claude -p --continue "<下一則>" --max-turns 4 >> ...
   ```
3. 每輪輸出存 transcript,逐情境對照判準給 PASS/FAIL,證據引述實際回應關鍵片段。

## 情境 1 — Fast-track(服務 A 直入)

**輪次**:1 輪,新對話。

**輸入訊息原文**:

```
幫我優化這份履歷：

姓名：陳小明
應徵目標：電商產業行銷企劃

工作經歷：
- 好好賣股份有限公司 行銷專員（2022/03–2025/06）
  負責社群貼文、辦活動、跟KOL聯絡、寫文案。
- 快快購有限公司 行銷助理（2020/07–2022/02）
  幫忙做報表、回覆客服訊息、上架商品。

教育學歷：
- 中華大學 企業管理學系 學士（2016–2020）

技能：Canva、Google Analytics、Facebook 廣告投放、Excel
```

**PASS 判準(二元)**:
- 不重走「問候 → 問稱呼 → 列服務選單」;
- 直接進入服務 A 流程;
- 以提問收尾後停止,不自問自答推進。

## 情境 2 — 訪談紀律(服務 B)

**輪次**:多輪,新對話起。逐輪輸入:

1. `我想使用服務 B，請透過引導式訪談幫我把最近一段工作經歷寫成履歷內容。`
2. `我最近一份工作是在一家物流新創擔任營運專員，做了大約兩年，主要負責倉儲調度和出貨流程。`
3. `我沒有現有履歷，直接進行訪談就好，我知悉並同意輸出只包含新工作經歷條目。`
4. `目標是轉往電商產業做供應鏈營運，主要考量是擴大職能範圍。`
5. `只寫物流新創這一段就好，2023/08 到 2025/07，職位是營運專員。`

**PASS 判準(二元,對每一輪回應)**:
- 每輪只問一個問題(一般資訊收集步驟允許一次列該步驟內多項資訊,見 SKILL.md 第 2 節;訪談階段嚴格單問);
- 提問後停止生成:回應結尾是問題,沒有代替使用者回答的內容;
- 出現「目前:服務 X 第 N/M 步」進度行(進入訪談段落後應加註「第 N 段／共 M 段・訪談階段 1–4」)。

## 情境 3 — 中途切換(B → C)

**輪次**:接續情境 2 的對話(服務 B 進行中),逐輪輸入:

1. `我想改做職缺分析。`
2. `保留已收集的資訊，我可以口述較完整的背景，請切換到服務 C。`

**PASS 判準(二元)**:
- 收到切換要求時先詢問是否保留已收集資訊,未經確認不切換;
- 使用者確認後才切換,且切到服務 C 第一步;
- 切換後不殘留服務 B 的步驟(進度行為服務 C,不再推進 B 的訪談)。

**備註(非 FAIL 的觀察)**:
- 情境 1 回應主體以兩個問題收尾,但最末段附一句非問句的提示(「您可以先行回想這些資料」);判準核心「不自問自答推進」成立,故判 PASS。若日後要求字面上「最後一句必須是問句」,此處是最可能翻紅的點。
- 情境 2 T3–T4 屬一般資訊收集步驟,一次列 2 項資訊並要求「一併回覆」,符合 SKILL.md 第 2 節的例外,不算違反單問紀律。
