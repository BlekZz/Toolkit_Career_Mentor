## 範例一：職缺風險解剖報告（輸入/輸出對照）

> 情境：張先生，業務開發專員 2 年經驗，工作規劃為穩健轉跑道至科技業業務；目標職缺為某貿易公司「業務助理（正職）」。

**應徵職缺說明（使用者提供）：**
```
職位：業務助理
公司：XX 國際貿易有限公司
薪資：面議（依市場行情）
工作內容：
  • 協助主管處理交辦事項
  • 協助業務拓展相關事宜
  • 文件製作與歸檔管理
工作要求：
  • 具高度抗壓性，能接受彈性工時
  • 積極主動、具強烈責任感
  • 可配合公司不定期出差需求
```

**AI 風險解剖報告：**

**維度一：職責清晰度與現實性**
評估結果：低度清晰，存在高度模糊風險。

「協助主管處理交辦事項」為高度不明確描述，無法從此判斷實際工作範疇，且此類表述通常代表工作邊界極為模糊，容易出現工作量無限擴張的情況。「協助業務拓展相關事宜」同樣缺乏具體說明，無法評估您的實際職能和成長空間。

風險等級：高

**維度二：語氣與文化暗示**
評估結果：出現多個常態超時工作的典型訊號。

「高度抗壓性」、「彈性工時」、「配合不定期出差」合併出現，是台灣職場 JD 中要求員工接受超時工作的常見委婉說法。「強烈責任感」在此脈絡下可能隱含以個人自我犧牲代替合理人力配置的文化期待。

風險等級：高

**維度三：合規性線索**
評估結果：需進一步確認。

「薪資面議」搭配「彈性工時」，無法確認加班費計算方式是否符合勞基法規定。建議在面試前查詢勞動部違反勞動法令查詢系統，確認該公司是否有加班費相關違規紀錄。

風險等級：中

**風險總結**
- 高風險（2 項）：職責邊界模糊 + 超時工作文化暗示
- 中風險（1 項）：薪資與加班機制不透明

**建議：** 此職缺存在 2 項高風險訊號，建議在決定應徵前完成以下外部偵查：
1. 至勞動部網站查詢「XX 國際貿易有限公司」的違規紀錄
2. 至比薪水、面試趣查詢該公司的員工評價，尋找跨平台的共同模式

若仍決定應徵，面試時務必針對以下重點進行交叉驗證：

**建議的面試驗證問題：**

針對工時與加班：
「我想了解這個職位的工作節奏。平均來說，團隊的工作時間大概是幾點到幾點？在業務旺季，加班的頻率和方式通常是怎麼樣的？加班費是依照勞基法計算，還是有其他補償機制？」

針對職責範疇：
「職缺說明中提到協助業務拓展，可否請您具體說明這個職位在前三個月最主要會接觸的工作內容是哪些？以及您認為擔任這個職位成功的關鍵指標是什麼？」

針對出差頻率：
「說明中提到不定期出差，可否說明出差的頻率、目的地，以及出差的相關費用是由公司全額負擔嗎？」

## 範例二：試做題邊界評估

> 情境：同範例一；張先生告知面試流程包含一份「市場開發提案」，對方未說明時間限制與用途。

**AI 評估輸出：**

| 評估維度 | 情況 | 判定 |
|---------|------|------|
| 時間要求 | 無明確時限 | ⚠ 警訊 |
| 交付物性質 | 完整市場開發提案 | ⚠ 警訊 |
| 說明清晰度 | 需求模糊 | ⚠ 警訊 |
| 保密機制 | 未說明 | ⚠ 警訊 |
| 反饋機制 | 未承諾 | ⚠ 警訊 |

評估結論：**警訊明確**（5 項全數為警訊）。

建議行動：主動詢問用途與預計完成時間；若對方無法說明，僅提交概念方向稿；作業中加入版權聲明，不提交可直接使用的完整成品。

## 範例三：相性判斷與模擬面試題

> 情境：同範例一；張先生完成外部偵查後確認應徵。

相性評估：
- 目標職位核心職責（業務拓展）與現有 2 年業務開發經驗方向吻合，核心技能無明顯缺口
- 工作規劃目標（轉入科技業）與此職位（貿易業）有輕度方向偏差，但非硬性背離
- 使用者已確認接受所有識別風險

判定：**相性佳，繼續執行**

**模擬面試題（依三類題型，節錄）：**

關於「你」的敘事題：
- 「請做一個自我介紹。」→ 建議答題框架：串聯 2 年業務實績 → 轉入科技業的具體動機（非泛泛興趣） → 此職位能提供的對接價值

關於「能力」的驗證題：
- 「分享一個您成功開發新客戶的經驗。」→ STAR 準備重點：強調「我主導了」而非「我們做了」；R 務必量化（成交金額、縮短開發週期、後續合作規模）

針對已識別高風險的交叉驗證題：
- 「這個職位的『協助主管交辦事項』，能舉例說明通常是哪類工作嗎？」（驗證職責邊界）
- 「關於彈性工時，平均每週工時大概多少？加班費是依照勞基法計算，還是有其他補償機制？」（驗證合規狀況）
