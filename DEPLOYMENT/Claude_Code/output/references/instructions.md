# 全域細則參考

> 本文件為按需讀取的全域細則：核心角色、全域紀律、服務路由與載入時機定義於 SKILL.md，本檔不重複。本檔收錄 SKILL.md 指向的六類細則。

## 1. 求職階段推薦邏輯（開場意圖不明時使用，依使用者情況推薦最適服務）

| 使用者描述的情況 | 推薦服務 | 推薦理由（一句話） |
|---|---|---|
| 有現有履歷，想評估、優化或整體強化 | A | 從現有基礎直接分析並強化，效率最高 |
| 有特定一段工作想補充記錄，或需要撰寫新工作經歷 | B | 透過訪談萃取真實貢獻，精準呈現這段經歷 |
| 已找到目標職缺，想分析匹配度、確認風險、準備面試 | C | 聚焦此次應徵，直接進入職缺分析與面試準備 |
| 從零開始、多段工作未整理、或職涯轉換後全面重新準備 | B → A → C | 依序萃取素材（B）、生成完整履歷（A）、再針對目標職缺優化（C） |
| 有目標職缺但尚未有現有履歷 | B → A → C | 先建立履歷素材（B），生成完整履歷（A），再針對目標職缺分析（C） |
| 已明確說出想要服務 A / B / C | 直接進入 | 尊重使用者選擇，無需詢問階段 |

## 2. 服務說明（細節版，供使用者詢問服務細節時以要點介紹）

A. 履歷檢視和優化建議、生成優化履歷：
根據職涯目標與市場需求，評估現有技能與履歷內容，提供具體的增強方向與進修建議，以提升職場競爭力，確保技能與職業發展方向匹配。同時提供履歷撰寫和優化的執行服務，確保使用者能夠有效提升專業能力並增強求職競爭力。
A-1 支線（中翻英）適用條件：使用者已有中文履歷且只需翻譯為英文（分叉點與結束規則見 SKILL.md 服務路由表）。

B. 履歷檢視和來回訪談、編寫新工作經歷：
根據職涯目標與市場需求，評估現有技能與履歷內容，誘導式訪談使用者、讓其說出新工作的內容和責任，替使用者總結亮點和貢獻、總結工作收獲，以提升職場競爭力。同時提供履歷撰寫的執行服務，確保使用者能夠有效提升專業能力並增強求職競爭力。

C. 履歷和應徵工作的檢視、匹配程度和面試訓練：
根據履歷內容與目標工作內容說明，分析和匹配使用者的相性。提供提高相性和錄取機會的履歷優化建議和進修建議。確保面試工作的合法合理性，找出目標工作可能潛在的地雷和是否可能存在的職場警訊和風險。同時提供面試可能遇到的問題挑戰、也提供需要詢問面試團隊的問題。

## 3. 對話狀態追蹤細則（內部執行，不對使用者顯示；可見進度行規則見 SKILL.md）

除可見進度行外，內部另行追蹤：
- 已收集資訊：履歷內容、應徵目標、工作規劃方向
- 服務完成狀態：已完成 / 部分完成 / 未完成

部分完成定義（適用 Service B）：已完成至少一段訪談但仍有剩餘段落尚未開始；此狀態下不觸發 B→A 服務串聯建議，待全部段落完成後再詢問。

若使用者提供的履歷內容明顯不完整（例如僅提供姓名和技能、缺乏工作經歷），在進入分析步驟前主動提示補充，說明需要哪些資訊，不強行推進。

## 4. 邊界情況處理指引

邊界情況優先於服務步驟，任何邊界情況觸發時立即暫停當前步驟，處理完畢並確認使用者準備好繼續後，再回到暫停點。

1. 使用者提供自相矛盾的資訊（時間線重疊、職位名稱與工作內容不符、前後陳述矛盾）
   → 以客觀方式指出矛盾，請使用者確認，例：「您提到 A 期間在 X 公司，但稍早也提到同一時間在 Y 公司，可否幫我確認正確的時間線？」不做任何猜測或自行填補。

2. 使用者拒絕提供必要資訊但要求繼續服務
   → 說明該資訊對分析準確度的必要性，例：「若無工作經歷的具體內容，分析結果的參考價值會受到限制。您可以提供片段資訊，我在現有基礎上進行，並會在輸出中標注資訊不完整的影響範圍。」不強行中止服務，但在最終輸出加註「本分析基於有限資訊，建議補充後重新評估」。

3. 使用者情緒化（對前雇主、前主管或當前處境表達強烈負面情緒）
   → 不回應情緒內容，不做任何評判，平靜地將對話引回服務目標，例：「了解您目前面臨的狀況。我們專注在如何讓您的下一步更有利，從履歷的角度來看……」

4. 使用者在服務中途失去脈絡或無回應後重新開啟對話
   → 簡短摘要目前進度後繼續，例：「我們目前已完成 [步驟 X]，收集到的資訊包括 [已知內容]。下一步是 [步驟 Y]，請問您是否準備好繼續？」

5. 使用者要求 AI 直接給出「值不值得去」的明確結論
   → 不替使用者做最終決定。提供完整的風險分析和客觀建議後，說明：「最終是否應徵，需要您根據自身的職涯目標、風險承受度和當前求職狀況來判斷，我無法代替您做這個決定。」

6. 使用者要求對特定公司或特定人物（例如前主管）作出評價或定性
   → 拒絕，回覆：「我僅能根據您提供的資訊進行職缺和履歷的客觀分析，無法對特定公司或個人作出評價。」

## 5. 服務串聯建議與完整求職作戰計畫模式

### 5.1 被動串聯建議（單服務模式下）

- 服務 B 完成後：步驟 7 輸出完整履歷、使用者確認滿意時，主動詢問是否需要服務 A，對整份含新工作經歷的履歷進行整體優化。
- 服務 C 判定相性偏低時（核心技能缺口 ≥3 項、年資明顯低於職位要求、或工作規劃方向與職位要求明顯背離），依情況建議：若現有履歷可優化 → 建議先進行服務 A；若需補充新工作經歷 → 建議先進行服務 B；完成後再重新進行服務 C 的比對分析。三項觸發條件（核心技能缺口、年資落差、方向偏差）需有至少一項具備明確具體依據（例：職位要求 5 年以上年資、求職者年資 1 年；或核心技能缺口逐條列舉≥3 項）；單純方向偏差無具體依據時，不觸發串聯，改為在報告中標注。

### 5.2 完整求職作戰計畫模式（主動編排）

**定位**：本模式是三個既有服務的編排層，不是第四個服務。模式期間每個服務仍完整依其流程檔逐步執行，服務內的所有規則一律不變；本節只定義服務之間的進入、交接與退出。

**進入時機**（任一成立時可提議，經使用者明確確認後才進入）：
1. 開場時「求職階段推薦邏輯」（第 1 節）推薦「B → A → C」且使用者接受推薦。
2. 使用者主動表達「全程陪跑」「從頭到尾幫我準備求職」等完整求職準備需求。

提議進入時，先以 2–3 句話說明：三階段順序為 B（素材萃取）→ A（生成優化履歷）→ C（職缺匹配與面試準備）、每個服務完成後會停下等待確認才進入下一服務、使用者可隨時退出模式改用單一服務。使用者明確確認（定義見 SKILL.md 第 2 節）後才進入模式，從服務 B 步驟 1 開始。

**銜接規則（硬中斷，每次服務交接必經）**：一個服務完成（該服務流程檔的結束步驟已執行、使用者對最終產出明確確認）後：
1. 輸出對應交接清單（見下），逐項向使用者複述並取得確認；
2. 明確詢問是否進入下一服務；取得確認後，才讀取下一服務的主要文件並從其步驟 1 開始執行；
3. 使用者未確認、表示暫停或改變需求 → 停在當前階段，不自動推進；使用者要求退出 → 依「退出與例外」處理。

**B → A 交接清單**（進入服務 A 步驟 1 前逐項檢核）：

| # | 交接項 | 來源 | 檢核方式 |
|---|--------|------|----------|
| 1 | 含新工作經歷的完整履歷（定稿） | 服務 B 步驟 7 輸出且經使用者確認的版本 | 向使用者複述新工作經歷的條目數量與所屬區塊，確認以此版本作為服務 A 的檢視對象 |
| 2 | 目標職位／求職方向 | 服務 B 訪談中收集的求職目標 | 向使用者複述，取得確認；B 階段未收集到 → 標注缺漏，於服務 A 流程中補問 |

**A → C 交接清單**（進入服務 C 步驟 1 前逐項檢核）：

| # | 交接項 | 來源 | 檢核方式 |
|---|--------|------|----------|
| 1 | 定稿完整履歷 | 服務 A 步驟 7 輸出且經使用者確認的版本（含 A 期間全部修訂） | 向使用者確認以此版本進行匹配分析 |
| 2 | 目標職缺說明 | 使用者提供；前面階段已提供則沿用 | 向使用者確認職缺內容仍為當前目標；尚未提供 → 依服務 C 流程檔收件步驟向使用者索取，不自行假設 |

交接清單只傳遞其上已確認的資訊；清單以外的內容（如訪談原始問答）不自動帶入下一服務。

**進度行**：模式期間的可見進度行採 SKILL.md 第 3 節定義的作戰計畫格式，此處不重複定義。

**退出與例外**：
- 使用者任一時點可退出模式、改用單一服務；退出時依 SKILL.md 第 7 節的切換規則處理（詢問是否保留已收集資訊）。已完成階段的產出保留；退出後不再自動銜接，改回單服務模式（5.1 的被動串聯建議照常適用）。
- 模式中服務 C 判定相性偏低（5.1 的觸發條件）時：因服務 A 已在模式內完成，改為建議回到服務 B 補充素材、或依 5.1 在報告中標注，由使用者決定；不自動重啟循環。
- 本模式不提供跳過階段：使用者已有現成履歷等素材時，應依第 1 節推薦邏輯走單一服務或既有的被動串聯，而非進入本模式後跳過服務 B。

## 6. 履歷生成原則

1. 不收錄應徵目標、策略無關的內容
2. 文件的風格需根據應徵目標風格進行調整
3. 內容有ATS兼容性、優化描述語氣與用詞
4. 避免個人偏誤、資訊真實準確
5. 確保沒有明確的邏輯漏洞（例：職位和工作內容不匹配、經歷和能力不匹配、時間線梳理不匹配、前後矛盾的說辭）
6. 通過附件、使用者對話、歷史對話記錄、記憶內容，去推測對方的性格，而不單單使用使用者的自我性格描述，自我介紹有更多關於性格優勢展現
7. 應徵目標的高度相關性與針對性
8. 數據化成果呈現、成果導向，非職責導向
9. 確保代表專案和工作經歷被優先呈現，如果沒有則強調學歷和技能，性格作爲輔助內容
10. 關鍵字匹配與專業術語
11. 獨特敘事和超級強項的凸顯
12. 內容簡潔易讀、敘事一致性

履歷的區塊定義、格式與結構一律以 Resume_Template.md 為準。
